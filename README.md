Исследование влияния состава целевой функции на эффективность оптимизации параметров встраивания цифровых водяных знаков методом роя частиц (PSO).

Цифровые водяные знаки (ЦВЗ) должны быть устойчивы к атакам: сжатию, шуму, фильтрации, геометрическим преобразованиям. При оптимизации параметров встраивания методом PSO ключевым становится вопрос: как выбор набора атак в целевой функции влияет на итоговую робастность и незаметность водяного знака.

В проекте реализован алгоритм встраивания ЦВЗ с PSO-оптимизацией и проведены эксперименты:
- Абляция — воспроизведение экспериментов из исходной статьи с варьированием количества атак.
- Исследование специализации — оценка переноса робастности на атаки, не входившие в целевую функцию.

- Arnold Cat Map — перемешивание пикселей водяного знака.
- PSO-оптимизация параметров встраивания.
- Набор состязательных и классических атак на контейнер.
- Метрики: PSNR, SSIM (незаметность), BER, NC (робастность).
- Скрипты для воспроизведения экспериментов с выгрузкой в Excel.

Установка 
git clone https://github.com/prosstofilya/praktos_watermarking.git
cd praktos_watermarking

python -m venv venv
source venv/bin/activate        # Linux / macOS
venv\Scripts\activate           # Windows

pip install -r requirements.txt

Полная серия экспериментов:
python run_all_experiments.py

Абляционное исследование:
python run_official_ablation.py

Исследование специализации:
python run_specialization_study.py
